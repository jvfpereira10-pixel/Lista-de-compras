Aplicação web para organizar a lista de compras da semana. Permite adicionar itens, marcar como comprados e remover da lista, com uma notificação visual confirmando a remoção.
O Quicklist ajuda a montar e acompanhar a lista de compras da semana. O usuário digita o nome do item e adiciona à lista; cada item pode ser marcado como comprado (checkbox) ou removido com um clique, recebendo um aviso de confirmação de que o item foi removido.

Tecnologias utilizadas
 
- HTML5
- CSS3
- JavaScript
